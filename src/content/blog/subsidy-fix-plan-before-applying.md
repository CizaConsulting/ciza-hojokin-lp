# 補助金は「採択後に変えられない」前提で申請する｜設備・実施場所・スケジュールをどこまで固めてから出すか

> 補助金は「採択されてから細部を詰める」ものではありません。むしろ **採択後にはほとんど変えられない** ことを前提に、どこまで固めてから申請するかを決めるのが、実務では最初の分かれ道になります。本記事は、設備投資系の補助金（省力化投資・ものづくり・新事業進出・成長加速化 など）を念頭に、申請前に固めるべきこと／ふわっとで良いことを整理します。

## 経営者が迷う、この場面

数千万円〜数億円規模の設備投資を、補助金を使って進めたい。締切は近い。しかし現場ではまだ、

- 導入する設備の**最終仕様・型式・見積が固まっていない**
- 工場のどのラインに、いつ入れるかの**実施場所・スケジュールが流動的**
- 投資の全体像は見えているが、**段階的に広げる計画で後半は未確定**

こういう状態は珍しくありません。ここで多くの経営者が「とりあえず締切に間に合わせて出し、細かいところは採択されてから詰めよう」と考えます。一見、機会を逃さない正しい判断に見えます。

## 一見正しい「まず出す」が危険な理由

補助金の手続きは、おおまかに **①申請 → ②採択 → ③交付決定 → ④発注・事業実施 → ⑤実績報告 → ⑥補助金の支払い** という順で進みます。「採択されてから詰める」が危険なのは、この後半の各段階に、後から動かせない制約が埋め込まれているからです。

- **交付決定より前の発注は、原則すべて補助対象外。** 「採択された」と「交付決定が出た」は別物です。採択通知の直後に発注してしまい、その経費が全額対象外になる——これは最も多い失敗のひとつです。
- **主要な設備の変更・実施場所の変更は、原則認められない。** 交付申請時に出した計画で実施するのが大前提です。「やっぱり別の機種に」「別の拠点に」は、変更申請で通ることもありますが、主要設備・実施場所ほど認められにくく、当初計画のまま進めるか交付を諦めるかの厳しい選択になります。
- **事業実施期間内に完了しないと対象外。** 業者の手配遅れや工事の延伸は「補助金側の事情」としては考慮されません。期限を1日でも越えれば対象外になり得ます。
- **採択後にも継続的な義務が残る。** 実績報告や数年にわたる状況報告、購入設備を申請した用途で使い続ける義務。ここを外すと不交付や返還につながります。

つまり「まず出す」は、**まだ決めていない事項を、後から変更しにくい申請内容として確定してしまう**ことになりがちです。締切に間に合っても、対象外・変更不可・期限超過で、補助金が実質的に使えなくなる。これが最悪のシナリオです。

## 判断基準：ふわっとで良いのは「方向性」、固めるべきは「申請書に落とす中身」

すべてを完璧に固めてからでないと動けない、という意味ではありません。切り分けは明確です。

**ふわっとで良い（むしろ早く動いてよい）**

- 「この補助金に、こういう方向で挑戦したい」という**構想段階**。制度の趣旨（お題）に賛同できるか、自社の方向性と合うかを見極める段階は、早いほど検討の時間が取れて有利です。

**申請書に落とす前に固める**

- **補助対象経費に載せる設備の仕様・型式・見積**（相見積が要る制度なら、その手当ても含む）
- **実施場所と、主要設備をどこに入れるか**
- **発注・納品・稼働までのスケジュール**（事業実施期間から逆算して現実的か）
- **段階的投資なら、補助金の対象にする範囲の切り出し方**

判断の軸はひとつです。**「採択後に変えられないもの」ほど、申請前に固める。**「計画の方向性」は変えても致命傷になりませんが、「対象経費・主要設備・実施場所・実施期間」は後から動かせないため、ここが未確定のまま出すのはリスクが最も高いのです。

実務では、構想が固まる前に申請書を書き始めると、訴求点が定まらず「書いては直し」を何度も繰り返すことになります。検討はふわっとで始めてよい。ただし**申請書の作成に着手するのは、対象経費と主要設備が固まってから**——これが最短ルートです。

## 制度別に見る「変更耐性」の違い

同じ設備投資系でも、変更のしにくさや設計の自由度は制度で異なります。制度選定の段階で、自社の「まだ決まっていない度合い」と制度の相性を見ておくと、後の手戻りを避けられます。

- **省力化投資補助金（カタログ注文型）**：カタログ掲載製品から選ぶため、対象や効果の考え方が定型的で、比較的迷いにくい類型です。一方、汎用製品の枠に自社の投資が収まるかが入口の判断になります。
- **省力化投資補助金（一般型）／ものづくり補助金**：個別の設備導入・システム構築に合わせて計画を作れる自由度がある反面、**工程・省力化の効果を定量的に示す設計が要り、仕様や工事範囲（例：機械専用の配線・付帯工事の扱い）が曖昧なままだと、対象経費の線引きが難しくなります。**「この費用は対象か」が不明確なまま走ると、見送りや作り直しの原因になります。
- **成長加速化・新事業進出など大型／計画重視の制度**：投資額・返済計画・賃上げ・体制まで一体で計画を組む必要があり、後半の投資が未確定だと計画全体の説得力が落ちます。段階投資なら、**どこまでを今回の補助対象に含め、どこからを自費・次フェーズにするか**を先に切り分けておきます。

> ※ 補助率・補助上限・対象経費・締切・要件の具体は制度・公募回ごとに異なり、変わります。必ず各制度の**最新の公募要領**で確認してください。本記事は手続き上の考え方を整理したものです。

## 申請前の実務チェック

- [ ] 交付決定が出るまで**発注しない**ことを、社内と現場に共有できているか
- [ ] 対象経費に載せる**設備の仕様・型式・見積**は固まっているか（必要なら相見積の手当ても）
- [ ] **機械専用の配線・据付・付帯工事**など、対象か対象外か曖昧な費用を洗い出し、線引きの根拠を確認したか
- [ ] **実施場所と主要設備の設置計画**は確定しているか（後から動かす前提になっていないか）
- [ ] **事業実施期間から逆算**して、業者手配・納品・稼働が現実的に収まるか
- [ ] 段階的投資の場合、**今回の補助対象範囲**を明確に切り出せているか
- [ ] 採択後の**実績報告・状況報告・用途遵守**の義務を、実行できる体制があるか
- [ ] GビズID等、申請に必要な**事前手続き**の所要期間を織り込んでいるか

## まとめ：締切ではなく「変えられなさ」から逆算する

締切に間に合わせることは大事ですが、間に合わせても対象外・変更不可・期限超過では意味がありません。**採択後に変えられないもの（対象経費・主要設備・実施場所・実施期間）を先に固め、方向性の検討は早く始める。** この順序を守るだけで、作り直しと「使えない採択」を大きく減らせます。

どこまで固めてから出すべきか、自社の投資計画のうち、どの項目が申請後に変更しにくいのかは、制度と案件によって変わります。判断に迷う段階でこそ、申請前の設計を一緒に整理しておくことをおすすめします。
